# Pronunciación local

125923 entradas derivadas de CMUdict, https://github.com/cmusphinx/cmudict (descargado 2026-10-04). Licencia conservada en LICENSE. Se convierten los fonemas ARPABET a una aproximación con caracteres hispanos; las vocales acentuadas señalan el énfasis. Las variantes permanecen como listas; la app usa la primera y advierte sobre el contexto en el detalle.

Cada archivo se carga por inicial y se conserva en Cache Storage si el navegador lo permite. No envía el libro a servicios externos ni llama a modelos. La primera descarga requiere conexión; posteriormente puede usar las iniciales guardadas. Las palabras sin entrada usan reglas ortográficas aproximadas y se identifican en el detalle de la frase.
